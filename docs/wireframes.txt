أبشر، نوسع التصميم الهيكلي النصي (Text-Based Wireframes) ونضيف له **الصفحة التعريفية للمنصة (Landing Page)** لتكون الواجهة الرسمية التي تظهر للزوار على الدومين الأساسي، والتي ستُبنى باستخدام React وتُستضاف مباشرة على السيرفر المحلي (Mini PC).

إليك التصميم الكامل للشاشات متضمناً الـ Landing Page وموزعاً بشكل مرئي ومقروء:

## 💻 2. لوحة المطور (Developer Dashboard)

### شاشة التسجيل وتأكيد الحساب (Auth & Verification Screen)

```text
+--------------------------------------------------------------------------+
|  CloudBase | Sign Up                                                     |
+--------------------------------------------------------------------------+
|  [ Full Name ]       -> 입력 (مثال: عيد الروّاف)                          |
|  [ Email Address ]   -> 입력 (يجب أن يكون فريداً)                          |
|  [ Password ]        -> 입력 (يتم تعميته عبر BCrypt)                     |
|                                                                          |
|  ( Button: Create Account )                                              |
+--------------------------------------------------------------------------+
|  IF Status == STATUS_UNVERIFIED:                                         |
|  [ ! ] "تم إرسال رابط التفعيل لبريدك. الرابط صالح لمدة 15 دقيقة فقط."    |
|  [ Button: Resend Verification Email ]                                   |
+--------------------------------------------------------------------------+

```

### الشاشة الرئيسية للمطور: وضع القراءة فقط (Read-Only Mode)

*تظهر للمطور فور تفعيل البريد وقبل صدور الموافقة الإدارية العامة.*

```text
+--------------------------------------------------------------------------+
| CloudBase | Dev Portal                        [ Welcome, Developer | Logout ]  |
+--------------------------------------------------------------------------+
|                                                                          |
|  [ ! ] تنبيه حوكمة: حسابك قيد المراجع الإدارية الآن.                     |
|      صلاحية الرفع (Deployment Capability) معطلة حتى ينشطها الأدمن.       |
|                                                                          |
|  +--------------------------------------------------------------------+  |
|  | نظام الحوكمة الحالي (Phase 1):                                     |  |
|  | Email Verified: ✅ YES                                             |  |
|  | Deployment Capability: ❌ DISABLED (Error 403 Forbidden)           |  |
|  +--------------------------------------------------------------------+  |
|                                                                          |
|  ( Button: 🔗 Connect GitHub Account ) -> بوابة الربط الآمن (OAuth)      |
+--------------------------------------------------------------------------+

```

### شاشة إنشاء مشروع جديد (Create Project Screen)

*تفتح للمطور فقط إذا تحول الـ Flag الإداري الحاكم إلى `is_deployment_enabled = true`.*

```text
+--------------------------------------------------------------------------+
| CloudBase | New Project                                                  |
+--------------------------------------------------------------------------+
|  [ Project Name ] -> 입력 (مثال: Wakeb Maps)                             |
|  [ Repository ]   -> القائمة المنسدلة (تُسحب ديناميكياً من جيت هوب)         |
|  [ Branch ]       -> القائمة المنسدلة (الافتراضي: main)                   |
|  [ Subdomain ]    -> [               ] .cloudbase.website                |
|                                                                          |
|  ( Button: 🚀 Submit Project Request )                                   |
|                                                                          |
|  * ملاحظة: سينتقل المشروع مباشرة لحالة PENDING_ADMIN_APPROVAL             |
|    بانتظار تخصيص الموارد (CPU/RAM Quotas) من قبل الإدارة.                |
+--------------------------------------------------------------------------+

```
